# Contributing
Thank you for your interest in contributing!

To ensure a smooth collaboration, please follow the guidelines below.

## Commits
Commit messages must follow the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) specification.

Additionally:
- The description must not exceed 50 characters.
- Each line in the commit body must not exceed 72 characters.

## Releases
Releases follow these specifications:
- [Semantic Versioning (semver.org)](https://semver.org/spec/v2.0.0.html)
- [Keep a Changelog (keepachangelog.com)](https://keepachangelog.com/en/1.1.0/)
